# Pong Game

A simple classic Pong game I made in Unity.

First to 5 wins.

**Play:** [Releases](https://github.com/Henryrouze/Pong-Game/releases)

Download the `.rar`, unzip the whole folder, and run `Pong Game.exe`.

## Modes

* **PVP** — Play against another person on the same keyboard.
* **PVE** — Play against the AI.

## Controls

**Player 1**

* W — Up
* S — Down

**Player 2**

* ↑ — Up
* ↓ — Down

**Esc** — Quit
